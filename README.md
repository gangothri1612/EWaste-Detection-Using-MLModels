# 🗑️ AI-Based E-Waste Detection System

## 📌 About

This project uses Artificial Intelligence to identify whether an object is **e-waste** or **non e-waste** from an image. It helps improve the recycling process by making waste sorting faster and more accurate.

## ✨ Features

* Detects e-waste using image classification.
* Compares different AI models like **XGBoost, Random Forest, SVM, and CNN**.
* Supports real-time detection with OpenCV.
* Displays results through a simple web dashboard.

## 🛠️ Technologies Used

* Python
* OpenCV
* XGBoost
* Random Forest
* SVM
* CNN
* Scikit-learn

## 📊 Results

Among all the models tested, **XGBoost** achieved the best performance with around **95% accuracy**, making it the most suitable model for e-waste detection.

## 🌍 Applications

* E-waste recycling centers
* Smart waste management
* Automated waste sorting
* Environmental sustainability

## 📌 Conclusion

This project demonstrates how AI can simplify e-waste detection and support efficient recycling. It provides a practical, accurate, and scalable solution for better waste management.
